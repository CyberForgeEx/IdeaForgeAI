# Contributing to IdeaForgeAI

Thank you for your interest in contributing to IdeaForgeAI! I welcome contributions from the community to help improve the AI-powered software idea evaluation platform.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/CyberForgeEx/IdeaForgeAI.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Test your changes
6. Commit your changes: `git commit -m "Add: description of your changes"`
7. Push to your fork: `git push origin feature/your-feature-name`
8. Open a Pull Request

## How to Contribute

### Reporting Bugs

If you find a bug, please open an issue with:
- A clear description of the problem
- Steps to reproduce the issue
- Expected vs actual behavior
- Screenshots (if applicable)
- Your environment details (browser, OS, etc.)

### Suggesting Features

I love new ideas! To suggest a feature:
- Open an issue with the "enhancement" label
- Describe the feature and its benefits
- Explain your use case

### Code Contributions

- Follow the existing code style
- Write clear, commented code
- Update documentation if needed
- Keep pull requests focused on a single feature or fix.

## Pull Request Guidelines

- Provide a clear description of what your PR does.
- Be responsive to feedback and requested changes

## Code of Conduct

- Be respectful and inclusive
- Welcome newcomers and help them get started (highly appreciated)
- Focus on constructive feedback
- Respect differing opinions and approaches

## Questions?

If you have questions about contributing, feel free to:
- Open an issue for discussion
- Visit website: https://www.ideaforgeai.online/
